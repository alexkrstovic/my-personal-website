# alexkrstovic.com

Personal portfolio site for Alex Krstovic — built with Next.js (App Router), React, and Tailwind CSS.

Live at [alexkrstovic.com](https://alexkrstovic.com).

## Features

- Home, Work, About, and Journal pages
- Case studies open as a sliding overlay (via parallel + intercepting routes) and are also real, shareable full pages
- Journal posts written in MDX
- Custom cursor with a magnetic hover effect on desktop
- Smooth scrolling via [Lenis](https://github.com/darkroomengineering/lenis)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Deployment

The site auto-deploys to [Vercel](https://vercel.com) on every push to `main`.
